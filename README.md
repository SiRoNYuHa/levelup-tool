# LevelUp Tool

성장 테이블을 보고 순위 조건을 판정하고, 전직변경 경로를 계산하는 Windows 데스크톱 도구입니다.

**릴리즈의 `LevelUpTool.exe`로 실행하는 것**을 기준으로 합니다. Python을 따로 설치하지 않아도 됩니다.

## 실행 방법

1. [Releases](https://github.com/SiRoNYuHa/levelup-tool/releases)에서 최신 `LevelUpTool.exe`를 받습니다.
2. 원하는 폴더에 두고 더블클릭합니다.
3. 창 제목은 **전직변경 경로 계산기**입니다.

저장 데이터는 exe와 같은 폴더의 `data` 아래에 만들어집니다. exe만 다른 곳으로 옮기면 예전에 저장한 캐릭터·프리셋이 안 보일 수 있습니다.

## 화면 구성

탭은 네 개입니다.

### 1. 조건 설정

순위 조건을 만들고 프리셋으로 저장합니다.

- 칸을 누르면 `비어있음 → 필수 → 선택` 순으로 바뀝니다.
- **필수**: 그 스탯이 전부 올라야 합니다.
- **선택**: 선택 칸 중 ‘선택 최소’개 이상이 올라야 합니다.
- **띵**: 한 줄에서 오른 스탯 총 개수 범위입니다.
- 아무 것도 설정하지 않은 순위는 판정에서 빠집니다. 위 순위부터 검사해 처음 맞는 순위가 됩니다.

### 2. 테이블

캐릭터별 성장 테이블을 편집합니다.

- 캐릭터 이름을 넣고 **저장**하면 그 캐릭터 테이블이 남습니다.
- 스탯 칸을 클릭하면 `●(+1)`이 켜지거나 꺼집니다. 줄 순서가 곧 레벨 순서입니다.
- 첫 줄 레벨, 줄 추가/삽입/삭제를 할 수 있습니다.
- **가져오기(CSV/JSON)** / **내보내기(CSV)** 로 여러 캐릭터를 한 번에 넣고 뺄 수 있습니다.
- 캐릭터 열이 없는 단일 테이블 파일을 가져오면 이름을 직접 지정합니다.

테이블 CSV 예 (`examples/tables_example.csv`):

```text
캐릭터,레벨,HP,힘,마력,속도,기술,방어,마방,행운,매력
예시캐릭터A,1,1,,1,1,,1,,1,
```

값이 `1`, `+1`, `o`, `x` 등이면 그 칸이 오른 것으로 봅니다.

### 3. 판정 결과

지금 열린 테이블을 선택한 프리셋으로 줄마다 순위를 매깁니다. Fail이 이어진 구간도 같이 보여 줍니다.

### 4. 최적 경로

시작 레벨부터 목표 레벨까지, 허용 순위를 맞추려고 어떤 줄을 수령하고 어떤 줄을 전직변경으로 지울지 계산합니다.

추가된 입력:

- **현재 스탯**: 캐릭터별로 저장합니다.
- **상한 스탯**: 캐릭터+직종별로 저장합니다. 빈 칸은 상한 없음입니다. CSV/JSON 가져오기를 지원합니다.
- 현재 스탯에서 캐릭터를 고르면 상한 쪽 캐릭터도 따라갑니다.
- **레벨당 전직변경**: 제한 없음 / 제한 있음.
- 계산 모드:
  - 허용 줄이 나올 때까지 순서대로 삭제
  - 전직변경 상한 안에서 허용 줄 최대화
- 결과 표에서 **상세보기**를 누르면 그 줄 이후의 현재/상한 스탯을 볼 수 있습니다.
- 상한에 이미 닿은 스탯은 그 줄에서 제외되고, 필수 조건에 영향을 주면 비고에 표시됩니다.

상한 스탯 CSV 예 (`examples/stats_example.csv`):

```text
캐릭터,직종,HP,힘,마력,속도,기술,방어,마방,행운,매력
예시캐릭터A,기사,40,30,20,35,30,30,20,20,20
```

## 저장 파일

exe(또는 소스)와 같은 폴더의 `data`입니다.

| 파일 | 내용 |
| --- | --- |
| `data/presets.json` | 순위 조건 프리셋 |
| `data/tables.json` | 캐릭터별 성장 테이블 |
| `data/characters.json` | 캐릭터별 현재 스탯 |
| `data/caps.json` | 캐릭터+직종별 상한 스탯 |

파일이 깨져 있으면 `.json.bak`으로 백업한 뒤 빈 상태로 다시 시작합니다.

## 주의 사항

**실행 오류가 발생할 확률이 있습니다.**

- Windows 전용입니다.
- SmartScreen이나 백신이 알 수 없는 게시자로 막을 수 있습니다. **추가 정보 → 실행**을 눌러야 할 수 있습니다.
- `C:\Program Files`처럼 권한이 필요한 폴더보다 사용자 폴더에서 실행하세요.
- 상한이 있는 상태에서 ‘허용 줄 최대화’ 모드는 경우의 수가 커지면 계산을 중단할 수 있습니다. 그때는 순서대로 삭제 모드를 쓰거나, 목표 레벨·전직변경 상한을 줄이세요.
- 테이블 줄이 목표 레벨보다 짧으면 중간에 멈춘다는 경고가 나옵니다.
- 프로그램을 안 켠 채로 덮어쓰지 마세요. 받는 중이거나 파일이 손상되면 바로 꺼질 수 있습니다.

## 이번 버전에 바뀐 점

이전 릴리즈(`v1.0.0`) 대비입니다.

- 성장 테이블을 **캐릭터 단위**로 저장·불러오기·삭제할 수 있습니다.
- 테이블/상한 스탯을 **CSV·JSON으로 가져오기**, 테이블은 CSV로 내보내기가 됩니다.
- 경로 계산에 **현재 스탯**과 **상한 스탯**이 들어갑니다. 상한에 닿은 스탯은 더 오르지 않습니다.
- **레벨당 전직변경 횟수**를 제한할 수 있습니다.
- 경로 결과 줄마다 비고와 **상세보기**(현재/상한, 이번에 오른 스탯, MAX)가 붙습니다.
- 결과 표에서 삭제한 줄은 회색 취소선으로 구분합니다.

## 개발자용 (선택)

소스에서 실행하거나 exe를 다시 만들 때만 사용합니다. 환경에 따라 오류가 날 수 있습니다.

```bash
python main.py
python -m unittest tests.test_core
```

Windows에서 `build.bat`을 실행하면 `dist\LevelUpTool.exe`를 다시 빌드합니다.
