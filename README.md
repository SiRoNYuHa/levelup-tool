# LevelUp Tool

성장 테이블을 보고 순위 조건을 판정하고, 경로를 시뮬레이션하는 Windows 데스크톱 도구입니다.

이 프로젝트는 **릴리즈에 올려 둔 `LevelUpTool.exe`로 실행하는 것**을 기준으로 합니다. Python을 따로 설치하지 않아도 됩니다.

## 실행 방법

1. 이 저장소의 [Releases](https://github.com/KMG180129/levelup-tool/releases) 페이지로 이동합니다.
2. 최신 릴리즈에서 `LevelUpTool.exe`를 받습니다.
3. 받은 파일을 원하는 폴더에 두고 더블클릭해서 실행합니다.

프리셋 같은 저장 파일은 exe와 같은 폴더의 `data` 아래에 만들어집니다. exe만 다른 위치로 옮기면 기존 저장 데이터가 보이지 않을 수 있습니다.

## 주의 사항

**실행 오류가 발생할 확률이 있습니다.** 아래 경우를 먼저 확인하세요.

- Windows 전용입니다. macOS나 Linux에서는 이 exe가 실행되지 않습니다.
- Windows SmartScreen이나 백신 프로그램이 **알 수 없는 게시자**로 차단할 수 있습니다. 그 경우 추가 정보 → 실행을 눌러야 할 수 있습니다.
- 다운로드가 끝나기 전에 실행하거나, 파일이 손상되면 바로 꺼지거나 오류가 날 수 있습니다.
- 관리자 권한이 필요한 폴더(예: `C:\Program Files`)에 두면 저장이 실패할 수 있습니다. 사용자 폴더에서 실행하는 것을 권장합니다.
- 프로그램이 안 켜지거나 중간에 멈추면, 환경에 따라 정상 동작하지 않는 경우가 있습니다. 다시 받거나 다른 폴더에서 실행해 보세요.

## 개발자용 (선택)

소스에서 직접 실행하거나 exe를 다시 만들 때만 사용합니다. 여기서도 환경에 따라 오류가 날 수 있습니다.

```bash
python main.py
```

Windows에서 `build.bat`을 실행하면 `dist\LevelUpTool.exe`를 다시 빌드하려고 시도합니다.
